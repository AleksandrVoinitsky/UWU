# Интернационализация (RU/EN)

## Механизм

Переводы хранятся в JSON-файлах `app/translations/{ru,en}.json`. Ключи —
семантические строки (`auth.login`, `menu.documents`, …), значения — переводы.

Логика — `app/core/i18n.py`:

- `translate(key, lang=None, **kwargs)` — возвращает перевод, при отсутствии ключа
  — сам ключ; поддерживает `str.format` для плейсхолдеров.
- `t` — короткий алиас для использования в шаблонах Jinja2.

## Выбор языка

- По умолчанию — `DEFAULT_LANGUAGE` (настройка сервиса).
- Веб-интерфейс — cookie `lang` (переключатель языка можно добавить в настройках).
- Администратор может задать язык пользователя (поле `User.language`).

## Добавление языка

1. Создать `app/translations/{код}.json` по образцу `ru.json`.
2. Добавить код в `SUPPORTED_LANGUAGES` в `app/core/i18n.py`.

## Добавление перевода

1. Добавить ключ в `ru.json` и `en.json`.
2. Использовать `{{ t('ключ', lang) }}` в шаблонах или `translate("ключ", lang)`
   в коде.
