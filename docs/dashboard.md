# Дашборд (главная торгового интерфейса)

## Назначение

Главная страница (`/`) для обычных пользователей — сводный экран с ключевыми
показателями торговли за выбранный период, с возможностью сравнивать периоды и
видеть динамику по дням. Заменяет прежнюю страницу из четырёх карточек на
длинный скроллящийся дашборд.

> Администратор на `/` автоматически перенаправляется в `/admin` и дашборд не видит.

## Периоды и сравнение

- Селектор периода (пилюли): **Сегодня / 7 дней / 30 дней / Этот месяц / Прошлый
  месяц / Квартал** + произвольный диапазон дат (поля «с — по»).
- По умолчанию — **этот месяц**.
- Каждая метрика сравнивается с **предыдущим периодом той же длины**
  (например, 1–22 сентября ↔ 1–22 августа), отображается стрелка ↑/↓ и процент.

Логика расчёта периодов — в [`app/web/trade.py`](app/web/trade.py):
`_period_range()`, `_resolve_period()`, `_pct_change()`.

## Метрики (KPI)

| Метрика | Источник | Сравнение |
| --- | --- | --- |
| Выручка | сумма проведённых расходных накладных | ↑↓ % |
| Прибыль | выручка − себестоимость | ↑↓ % |
| Средний чек | выручка / кол-во продаж | ↑↓ % |
| Продажи (чеков) | кол-во расходных накладных | ↑↓ % |
| Закупки | сумма проведённых приходных накладных | ↑↓ % |
| Деньги в кассе | остаток денежных средств | мгновенно |
| Стоимость склада | сумма себестоимости остатков | мгновенно |
| Нам должны (дебиторка) | положительные взаиморасчёты | мгновенно |
| Мы должны (кредиторка) | отрицательные взаиморасчёты | мгновенно |

## Секции

1. **Герой-блок** (`dash-hero`) — главный показатель (выручка) крупным числом с
   анимированным счётчиком, сравнение с прошлым периодом, мини-статистика
   (продажи, средний чек) и селектор периода.
2. **Быстрые действия** — создание накладной/прихода/перемещения/ПКО/РКО + РМК
   и документы (с иконками).
3. **KPI-карточки** (`kpi-grid`) с иконками: выручка, прибыль, средний чек,
   продажи, закупки; ниже — «Текущее состояние» (деньги, склад, дебиторка,
   кредиторка).
4. **Выручка и прибыль по дням** — линейный график Chart.js (локальный файл
   [`app/static/js/chart.umd.min.js`](app/static/js/chart.umd.min.js), работает
   офлайн; цвета берутся из токенов темы).
5. **Топ-10 товаров** и **топ-10 клиентов** по выручке.
6. **Последние продажи** (лента: №, клиент, сумма) и **низкие остатки**.
7. **Рекомендации к заказу** — список всей номенклатуры с расчётом оптимального
   остатка и рекомендуемого количества к заказу (с пагинацией).

Оформление (герой, KPI, иконки, тёмная тема, анимации) — см.
[design-system](design-system.md).

## Рекомендации к заказу у поставщика

Механика на основе продаж (min-max / точка заказа) для каждой позиции
номенклатуры:

- **Средние продажи/день** = продано за `lookback` дней ÷ `lookback`.
- **Точка заказа** = средние продажи × срок поставки (`lead` дней).
- **Оптимальный остаток (target)** = средние продажи × (поставка + страховой
  запас `safety` дней).
- **К заказу** = `target − остаток` (если положительно).

Статус позиции: «Заказать» (остаток ≤ точки заказа), «Достаточно», «Нет продаж».

Параметры настраиваются константами (`reorder_lookback_days`, `reorder_lead_days`,
`reorder_safety_days`) с значениями по умолчанию 30 / 7 / 3 дня.

## Техническая реализация

Агрегаты добавлены в [`app/services/report_service.py`](app/services/report_service.py):

- `sales_summary(session, start, end) -> dict` — выручка, прибыль, себестоимость,
  количество продаж, средний чек, закупки за период.
- `daily_sales(session, start, end) -> list[dict]` — выручка/прибыль по дням
  (дни без продаж заполняются нулями).
- `top_items(session, start, end, limit=10)` — топ товаров по выручке.
- `top_counterparties(session, start, end, limit=10)` — топ клиентов.
- `low_stock(session, threshold=5, limit=10)` — товары с низким/нулевым остатком.
- `recent_sales(session, limit=10)` — последние проведённые продажи.
- `replenishment_recommendations(session, lookback_days, lead_days, safety_days)` —
  рекомендации к заказу по всей номенклатуре (оптимальный остаток и количество к заказу).

Маршрут: `GET /` в [`app/web/trade.py`](app/web/trade.py). Шаблон —
[`app/templates/trade/dashboard.html`](app/templates/trade/dashboard.html).
Данные для графика передаются как JSON (`chart_labels_json` и др.).

Интернационализация: ключи `dashboard.*` и `period.*` в
[`app/translations/ru.json`](app/translations/ru.json) и
[`app/translations/en.json`](app/translations/en.json).
