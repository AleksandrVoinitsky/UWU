# UWU — документация

UWU — многопользовательский веб-сервис автоматизации торгового и складского
учёта, повторяющий функционал «1С 7.7: Торговля и Склад» (редакция 9.0), но
реализованный как современный сервис на Python/FastAPI + PostgreSQL,
разворачиваемый в Docker.

## Быстрый старт

```bash
# 1. Скопировать настройки и задать пароль администратора
cp .env.example .env

# 2. Запустить сервис и базу данных
docker compose up --build

# 3. Открыть http://localhost:8000
```

При первом запуске создаётся учётная запись администратора (логин/пароль из
переменных окружения `ADMIN_LOGIN` / `ADMIN_PASSWORD`). Администратор попадает в
интерфейс управления (пользователи, роли, настройки, документация), обычные
пользователи — в торговый интерфейс.

## Ключевые принципы

- **Чистый расширяемый код** — разделение на слои (модели → сервисы → API/Web),
  SOLID, TDD.
- **Партионный учёт** — себестоимость по партиям, метод списания FIFO/LIFO/средняя.
- **Двойная валюта** — валюта бухгалтерского и управленческого учёта.
- **Безопасность** — bcrypt-хеши паролей, JWT-токены, ролевая модель прав.
