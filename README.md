# UWU

Многопользовательский веб-сервис автоматизации торгового и складского учёта,
повторяющий функционал «1С 7.7: Торговля и Склад» (ред. 9.0), реализованный как
современный сервис на **Python / FastAPI + PostgreSQL**, разворачиваемый в
**Docker**.

## Возможности

- **Справочники (НСИ)**: номенклатура (иерархия, свойства), контрагенты
  (+договоры, расчётные счета), склады, фирмы, кассы, валюты (+курсы), единицы,
  ставки НДС, типы цен.
- **Документы** с проведением: приход/расход (наличный/кредит/реализация),
  перемещение, списание, оприходование, инвентаризация, переоценка товаров,
  ввод остатков, возврат, ПКО/РКО, платёжное поручение.
- **Контроль остатков** (по складу/по фирме/без контроля).
- **Партионный учёт** и себестоимость (FIFO / LIFO / средняя).
- **Взаиморасчёты** и **денежные средства**.
- **Автоматические бухгалтерские проводки** при проведении (товары, деньги,
  себестоимость, переоценка, ввод остатков).
- **Многофирменный учёт** — движения денег и взаиморасчётов с привязкой к фирме,
  отчёты по фирме.
- **Отчёты**: остатки, движения, продажи, взаиморасчёты, деньги, ABC-анализ,
  кассовая книга, оборотная ведомость, карточка товара, книга покупок/продаж.
- **Роли и права**: администратор (управление пользователями, ролями,
  настройками, документацией) и оператор/бухгалтер (торговый интерфейс);
  права проверяются и на REST API, и на веб-слое.
- **Безопасность**: bcrypt, JWT, rate limiting входа, CSRF-защита, fail-fast
  небезопасных настроек в production.
- **i18n**: русский и английский.
- **Встроенная Markdown-документация** в админке.

## Быстрый старт

```bash
cp .env.example .env          # задать ADMIN_PASSWORD и SECRET_KEY
docker compose up --build
```

Открыть http://localhost:8000 и войти под `ADMIN_LOGIN` / `ADMIN_PASSWORD`.

`docker compose up --build` поднимает три сервиса: `db` (PostgreSQL 16 +
pgvector), `app` (ядро учёта) и `agent` (AI-консультант `uwu-ai-agent`,
отдельный контейнер-клиент REST API ядра, порт 8100). Агент аутентифицируется
API-ключом из `AGENT_API_KEY` (ядро создаёт его при старте); без `LLM_API_KEY`
работает в детерминированном fallback-режиме. Подробнее — [`uwu-ai-agent`](uwu-ai-agent/README.md)
и [docs/ai-agent.md](docs/ai-agent.md).

## Демо-данные (тестовый каталог)

```bash
# 130+ товаров в 14 категориях с ценами, остатками и приходными накладными
docker exec -w /app -e PYTHONPATH=/app uwu-app-1 python scripts/seed_catalog.py
```

Скрипт [`scripts/seed_catalog.py`](scripts/seed_catalog.py) идемпотентен и
создаёт тестовый каталог товаров, распределённых по разным категориям, с
закупочной и розничной ценой, плюс минимальную инфраструктуру (склад, фирма,
контрагент, тип цен) и приходные документы для ненулевых остатков.

## Тесты

Тесты работают с **изолированной тестовой БД `uwu_test`** (сервис `db_test` в
`docker-compose.yml`), а не с рабочей `uwu` — чтобы `TRUNCATE`/`drop_all` в
тестах не затирали реальные данные. Поднять тестовую БД и прогнать тесты:

```bash
docker compose up -d db_test         # тестовая БД (хост-порт 5433)
pip install -r requirements.txt
pytest tests/ -v
```

`tests/conftest.py` сам указывает на `localhost:5433/uwu_test`.
